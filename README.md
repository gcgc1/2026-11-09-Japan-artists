# 2026-11-09-Japan-artists

A two-hour course on six Japanese artists — Yayoi Kusama, Issey Miyake, Rei Kawakubo, Yohji Yamamoto, Yoshitomo Nara, and Takashi Murakami — built for a trip to Japan.

Start here: open [`index.html`](./index.html) in a browser.

## What is here

- `index.html` — the course home and the 2-hour route.
- `lessons/` — seven self-contained lessons with images, videos, and quizzes.
- `reference/` — printable timeline, venue guide, glossary, and looking prompts.
- `MISSION.md` — why this workspace exists and what success looks like.
- `RESOURCES.md` — the sources and communities behind the lessons.
- `GLOSSARY.md` — the course’s working vocabulary.
- `assets/` — the shared stylesheet, quiz/video components, and image credits.

## How to use it

Open `index.html` directly; the course is static HTML, with no build step and no server. The images and video posters are local; the videos load from YouTube when you click them. Every lesson links to the next, and the reference sheets are designed to be printed.
